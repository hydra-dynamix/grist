# Normalized rendering and source maps

`grist::render::render_document_graph` renders `DocumentGraph` to normalized
Markdown, LaTeX, safe HTML, plain text, or canonical JSON. Callers select a
`RenderFormat` and an explicit `FidelityMode`:

- `strict` rejects the first node the target cannot represent.
- `raw_fallback` preserves retained source syntax in a target-specific inert
  block marked with the node ID, parser namespace, and original kind.
- `lossy` omits unsupported nodes and emits one `RenderLoss` plus one lossy
  diagnostic naming each affected node.

The default is `strict`; lossy behavior is never inferred. Canonical JSON uses
Grist's single canonicalization implementation and preserves every graph field,
including retained raw content.

Every non-empty generated byte belongs to exactly one ordered, half-open
`RenderSourceMapEntry`. Ranges use UTF-8 byte offsets and identify the source
node. The original nested `SourceLocator` and its exact, approximate, or
synthetic status are copied when available. A node without a locator is mapped
with status `unavailable` and an explicit reason, never an invented location.
`RenderSourceMap::validate` checks length, ordering, gap-free coverage, UTF-8
boundaries, node IDs, and locator declarations.

HTML uses a fixed safe element vocabulary, escapes all text and attributes, and
blocks active URI schemes. Markdown escapes active HTML and uses variable-length
code fences. LaTeX escapes commands and places raw fallback syntax inside inert
literals. Grist never executes or fetches rendered content.

`RenderFidelity::reconstruction_claim` is always
`normalized_not_byte_round_trip`. Package reconstruction is a separate
format-specific operation; normalized output must not be presented as original
bytes or faithful package reconstruction.

Public JSON schemas are registered as `render-result`, `render-source-map`, and
`render-options`.

Graph-operation envelopes and format-specific reconstruction are documented in
`docs/transform-reconstruction.md`. Renderers never consult reconstruction
claims and cannot upgrade normalized output into a package fidelity claim.
